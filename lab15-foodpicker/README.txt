เปิด index.html ด้วย Live Server เพื่อทดลองเว็บ
การส่งงานจริง:
1. สร้าง GitHub repository และอัปโหลด index.html, style.css, script.js, images/ ไปไว้ที่ root
2. Import repository เข้า Vercel และเลือก Framework Preset: Other
3. ตั้งชื่อ Project: itf-itxxxxxxxx โดยแทน x ด้วยรหัสนักศึกษา
4. เมื่อ Deploy สำเร็จ บันทึก URL จริงลง url.txt
5. แคปหน้าจอเว็บเป็น website.png
6. หากใช้ AI ในการสร้างเว็บ แนบหลักฐาน Prompt ด้วย
7. ZIP โค้ดและหลักฐานเพื่อส่งงาน
